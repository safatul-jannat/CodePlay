CodePlay is an OOP-based gaming platform where users interact with high-level objects like Player, Ground, Enemy, and Game. Physics and input handling are encapsulated within objects - users just call methods on these objects to create amazing games!

Key Features:
• Object-oriented game development
• Pre-built game objects (Player, Enemy, Ground, etc.)
• Encapsulated physics and input systems
• Real-time object interaction
• Visual feedback for all object actions
• Simple method calls for complex behaviors
