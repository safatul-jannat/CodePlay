ABOUT CODEPLAY

CodePlay is an educational gaming platform built to teach Object-Oriented Programming through game development.

HOW IT WORKS

Users write Java code using pre-built game entities like BlockPlayer (the character), Collectible (coins/powerups), Enemy, Ground, and KillZone. Each entity has built-in physics, collision detection, and customizable properties.

The game runs in real-time with:
• Gravity and movement physics
• Keyboard/mouse input handling
• Health and damage systems
• Score tracking for collectibles

WHY WE MADE IT

Learning OOP concepts like inheritance, polymorphism, and encapsulation can be abstract and difficult. CodePlay makes these concepts tangible by letting students see how Java classes interact in a living, playable game world.
